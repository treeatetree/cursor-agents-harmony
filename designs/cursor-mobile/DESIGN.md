# Cursor Mobile — 已锁 beUI

HTML 精致化中，ArkTS 未动。

## 场景怎么驱动界面（资深审查）

指挥台的四件事，按紧急程度，不是按仓库字母序。

| 用户在干什么 | 界面必须做到 | 不该做 |
|---|---|---|
| 外屏 2 秒分诊 | 运行中、失败的组排在前面；组内也按运行 → 失败 → 有 PR → 其余 | 先看到两天前的环境搭建 |
| 点进一张卡 | 看到的是**这张卡**的原话、结果或错误 | 失败卡打开却是别人的成功正文 |
| 失败（401） | 一行说清原因，主操作是「去设置」 | 假装有 PR、有正文层级 |
| 完成且有 PR | 墨色 PR chip 是主操作；分支可复制 | 再写一遍「已完成」 |
| 运行中 | 当前文件最重；停止在输入行 | 顶栏再报一遍用时 |
| 派新任务 | 点仓库名换最近用过的仓；「更多」里改自动 PR | 把能力做成空芯片 |
| 设置 | 齿轮进设置（账号是第一件事）；更换 Key 能贴 | Inbox 用 ··· 假装设置 |

筛选仍是四档（跟现网一致），不靠新筛选项做分诊，靠排序。详情右上 ··· 才是次要操作：浏览器 / 复制分支 / 打开 PR / 归档。

## 信息放哪（密度）

每条信息只出现一次。位置按「扫一眼要什么」排。

| 面 | 留下 | 拿掉 | 补上 |
|---|---|---|---|
| Inbox 卡 | 标题 + 一步/结果 + PR 或失败 + 时间 | 分组下再写仓库；有 PR 不再写「已完成」；运行中不写「运行中」（边框+跳秒已够） | 标题最多两行；结果最多两行 |
| Inbox 分组 | 短仓库名 | `owner/repo`、右侧个数 | — |
| Inbox 顶栏 | 四档筛选；外屏/横屏不要搜索 | 内屏竖空点的搜索图标 | 内屏竖点搜索出输入；横屏主栏用「运行/完成」短标 |
| 横屏主栏行 | 标题 + PR/失败 + 时间 | 中间结果行（右侧已是详情） | 当前选中行描边 |
| 新建 | 铺满写作面；仓库常驻；模型在「更多」里写出名字 | 顶栏教怎么用 | — |
| 详情顶栏 | 标题 + 仓库；运行中加「运行中」 | 顶栏再写一遍用时；「运行 1」分隔行；底栏再写已完成/PR/用时 | — |
| 详情过程 | 一行：「推理中 · 12s」或「过程 · 18s · 4 步」 | 推理、探索拆成两行 | 完成后露出分支，点一下复制 |
| 详情追问 | 底栏只留输入和发送；两条追问点进输入 | 追问壳再挂仓库/更多 | — |
| 设置 | 姓名 + 邮箱/Key 一行；阅读和任务都用开关 | 「当前系统 · beUI」产品里不出现；偏好写成「开」 | 默认模型；更换 Key |

留白：分组间距 `--sec`（舒适 12 / 紧凑 8）；卡片内边距舒适 12 / 紧凑 10；详情时间线顶 4、底 8；追问壳比新建壳矮一截。四屏顶栏同一套 44 热区。封面和内屏竖卡片字段相同，不因变宽再塞仓库。

动效契约（CSS only，180–280ms；`prefers-reduced-motion` 全关）：

- Inbox：筛选底滑动 pill；卡片按下 0.98；运行中时间等宽跳秒
- 新建：壳铺满；「更多」展开模型/图片/能力；空发抖；发出去描勾（墨色，不用绿糖）
- 详情：推理浅闪 + 用时；轨迹带类型词（同色，不彩虹）；改动 chip；完成后两条追问
- 设置：弹簧开关

# 三套对照（已锁 beUI）

| 系统 | 新建 | 详情过程 | 强调色 |
|---|---|---|---|
| **Now** | 空画布 + 底栏发送 | 过程一行 / 改动 chip / 正文分阶 | 铜 `#C45C26`，只给运行和发送 |
| **HeroUI** | PromptInput 壳，字写在壳里 | 同上三层；追问也是壳；运行中发送变停止 | 官方蓝 `#0485F7`；Inbox 用 Segment 轨道 |

# 收口约束（三套都遵守）

前面把 baoyu-design、HeroUI、BeautifulUI、kill-ai-slop、折叠三态、换肤对比拆成多轮，结果是**同一骨架刷三遍色**。下面按你提过的全部约束，收成**一套产品**，不再并排卖皮肤。

## 你提过的全部条件

| 来源 | 要求 | 收口 |
|---|---|---|
| 产品 | 云端 Agent **指挥台**，不是聊天 App | 详情是任务时间线，不做 Chat Tab |
| 产品 | Inbox 封面双列；新建空画布 + 芯片，不堆表单 | 封面/内屏竖保持双列；**内屏横主栏改单列行**（38% 宽再双列不可读） |
| 设备 | Pura X Max：外屏竖为主；内屏要竖+横 | 459×672 / 664×939 / 939×664 Split |
| 鸿蒙 | 无毛玻璃；阴影不当主层次；token 能落到 `Tokens.ets` | 发丝线；HTML 里也不用大阴影 |
| baoyu-design | HTML 先于 ArkTS | 本目录是稿；`color.json` 先冻结 |
| kill-ai-slop | 去纸纹、左色条、焦糖底、彩虹状态、emoji | 中性底 + **一条**强调色 |
| HeroUI | 参考官方原则/组件，不是抄营销渐变 | Segment、soft chip、44/22 图标、发送在输入行 |
| BeautifulUI | 只搬对得上的 Agent 原语 | 思考展开、Tool chip、elapsed、Prompt 底栏 |
| 体验 | 字号/密度可调；深浅色；字阶与图标要像成熟产品 | 设置里三档：外观 / 字号 / 密度 |
| 体验 | 对话里 Agent 输出要有层级，重点适时突出 | 过程折叠、改动 chip、正文分阶；见「输出层级」 |

## 场景（先于画板）

1. **外屏，约 2 秒**：谁在跑、谁失败、谁已经开了 PR。卡片中间行必须是**这一轮的结果或步骤**，不是再写一遍仓库名。
2. **内屏竖**：浏览 + 点进任务。顶栏可以露出搜索。
3. **内屏横**：左栏点任务，右栏看时间线或写新任务。左栏是**行**，不是缩小的双列卡。
4. **新建**：先写「要做什么」。仓库是唯一常驻上下文；模型/图/能力进「更多」。发送在输入行，不在标题栏装成设置。

## 现网不合格（字阶 / 图标）

`Tokens.ets` 有阶梯 22/17/16/15/14/13/12，但页面大量写死 12–17，设置页几乎不用 token。HTML 稿用了 11px、字重 560、`···` `↑` `+` 当图标，和真机 `HuIcon` 22@44 不是一套语言。

**本套稿的字阶（与 Tokens 对齐，只准用这些）：**

- 标题 17 Medium — 页标题
- 正文 15 Medium — 卡片标题
- 阅读 16 Regular — 时间线散文
- 标注 14 Regular — 按钮、输入
- 说明 13 Regular — 分组、设置小节
- 微字 12 Regular — 时间、状态、芯片

禁止 11px。字重只 Regular / Medium。

**图标：** 单套填充形，22px 画在 44 热区里。返回 / 更多 / 加号 / 发送 / 搜索。不加号文字、不用箭头字符。

## 一套视觉

- 底：锌灰浅 `#FAFAFA` / 深 `#0B0B0C`（跟现网 Quiet，深浅成对设计，不是浅色倒一下）
- 强调：铜 `#C45C26` / 深色 `#E07A3D`，**只给运行中与发送**
- 失败用字色；完成用墨灰，不上绿糖
- 卡片：标题 + **一步/结果** + 状态或 PR + 时间。分组已写仓库，卡内不再重复

## 可调（为外屏视力与内屏阅读）

- **外观** 跟随 / 浅 / 深
- **字号** 标准 / 偏大（整体 1.0 / 1.12，行高跟着走）
- **密度** 舒适 / 紧凑（卡片内边距，不缩放整个界面）

## 输出层级（详情时间线）

现网详情把推理、工具、正文铺成同一重量：每条都是 `bg2` 卡 + 12–14 号字。Cursor 桌面端不是这样。

桌面端（Agents 窗，2026 官方说明 + 现网行为）把一轮拆成三层：

| 层 | 什么 | 默认 |
|---|---|---|
| **过程** | 推理；读 / 搜 / glob / list / 网页 | 收成一行。跑完是「推理 18s」「探索 4 步」。设置里 Detailed 也不会把探索步骤默认摊开 |
| **改动** | 改文件、终端、产物、PR | 比过程重一档。Detailed 下编辑和终端会顶出来；手机上用文件 chip，不进过程折叠 |
| **正文** | Agent 写给你看的话 | 唯一全宽阅读面。标题分段，列表缩进，代码沉底 |

时间：正在跑时，**只有当前动作**用铜色；上一秒的读/搜立刻退回过程行。跑完后过程默认合上，正文留下。

手机不抄桌面的「Worked for 15m」套娃——外屏只有一次展开。点过程行看细节，不要再套一层手风琴。

**正文自己也要有阶梯**（这是「读起来累」的另一半）：

- 首段：结论，16 / 24，墨色
- `h2`：17 Medium，上边距大，当扫描锚点
- 列表：同号，标记用三级色
- 围栏代码：13 等宽，沉在 `bg2` 里，带语言和复制
- 行内代码：略小、底浅，不跟正文抢
- 用户原话：14，退一层，它是上下文不是答案

现网 `MarkdownLite` 已能解析标题/列表/代码，但 h1/h2 和正文几乎同色同重，工具卡又和正文一样白。先在 HTML 里把层级做对，再改 ArkTS。

密度以后可以对齐桌面 Conversation Density：紧凑 = 过程更收；舒适 = 改动 chip 仍在。探索步骤始终默认折叠。

## 明确不做

BeautifulUI 的 Chat Tab、Diff 表、CRM、Insight 图；外屏横；半折；假状态栏；对比未结束就刷真机 `color.json`；桌面那种多层「Worked for Ns」嵌套。
